# 翻译数据目录说明

本目录用于组织与合并闪耀色彩中文翻译数据：

- `upstream/`：由 CI 定时同步自社区仓库 [`ShinyGroup/SCTranslationData`](https://github.com/ShinyGroup/SCTranslationData)（`master` 分支），请勿手工修改。
- `local/`：本项目的人工修订与补译内容。
- `ai/`：AI 辅助补译内容，格式与社区 CSV 一致，`译者` 行标注为 `AI(<模型名>)`。

## 合并优先级

同一剧情路径或同一词条键存在多个来源时，遵循：

`upstream（社区人工译文） > local（本项目人工译文） > ai（AI 机翻）`

## 来源与署名声明

- 全部社区译文版权归原译者与 ShinyGroup 社区所有，构建与展示过程中保留所有译者署名。
- 上游仓库未附带开源许可证，本项目仅作复用与署名，不主张对社区译文的版权。
- 录制包含他人译文的剧情视频并发布至公开网站前，请先取得对应译者同意。
